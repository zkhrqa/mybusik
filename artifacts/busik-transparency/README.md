# Бусик: пробное удаление зелёного фона

Источник: да_сгенерируй_с_прозрачным_фон.mp4 из папки пользователя.

- busik-transparent-master.mov — ProRes 4444 с альфа-каналом, 1280×720, 24 кадра/с, 10 секунд; без звука.
- busik-transparent.webm — VP9 с альфа-каналом, те же размер и длительность; вариант для проверки в веб-интерфейсе. Совместимость с целевыми браузерами пока не проверена.
- busik-background-check.mp4 — сравнение движения на светлом и тёмном фоне; это демонстрация, без прозрачности.
- busik-transparent-frame.png — отдельный кадр с прозрачностью.
- busik-export-check.jpg — кадр, декодированный из экспортированного WebM, на двух подложках.
- busik-review.jpg — выборка кадров по всему ролику.

Зелёный фон удалён по преобладанию зелёного канала с мягкой границей. Уменьшены зелёные оттенки по контуру и убрана встроенная звёздочка справа внизу.

Проверено: обработано 240 кадров; повторное декодирование MOV и WebM подтвердило прозрачные, непрозрачные и полупрозрачные пиксели. По выборке кадров проверены две подложки. Это пробная автоматическая обработка: тонкий ореол и остаточные оттенки на шерсти могут потребовать ручной доработки. Исходный ролик сохранён без изменений.

Видеофайлы MOV, WebM и MP4 оставлены только локально и исключены из Git по просьбе владельца. В репозитории сохранены описание и проверочные изображения.
