# mybusik / «мой бусик»

Интерактивные личные подарки для пары: воспоминания, секрет, сердце, фото-пазл, автомат свиданий и купоны. Маскот Бусик сопровождает этапы.

## Структура

- `mybusik-prototype/` — React + TypeScript + Vite, Motion, мобильный прототип.
- `design/mybusik-product-brief.md` — единый продуктовый бриф и текущие решения.
- `design/busik-animation-brief.md` — задания на анимации Бусика.
- `design/concepts/` и `design/assets/` — визуальные направления и материалы персонажа.
- `design/audit/` — материалы исследования OnlyTeplo.

## Локальный запуск

```sh
cd mybusik-prototype
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Проверка: `npm run build` внутри `mybusik-prototype/`. Она включает TypeScript и проверку целостности защищённого мобильного шаблона.

## Текущий статус

Это локальный прототип с шестью базовыми механиками и выбором подачи этапов. Серверное хранение, рабочие ссылки на подарки, оплата, уведомления, десктопная компоновка и готовые анимации персонажа ещё не подключены. Данные теряются после обновления страницы.
