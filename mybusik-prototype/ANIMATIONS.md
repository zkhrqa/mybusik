# Анимации mybusik

Подключены отдельные исходники React Bits и Magic UI. Это библиотеки копируемых компонентов: целые репозитории не нужны в приложении. Новые эффекты добавляем из их официальных реестров по мере необходимости.

## React Bits: FlipCard

- Репозиторий: https://github.com/DavidHDev/react-bits
- Документация: https://reactbits.dev/micro/flip-card
- Использованный исходник: https://reactbits.dev/r/FlipCard-TS-CSS.json
- Локальные файлы: `src/components/react-bits/FlipCard.tsx`, `FlipCard.css`.
- Импорт: `import FlipCard from './components/react-bits/FlipCard';`
- Зависимость: уже установленный `motion`.

В предоставленном промпте `<undefined />` и `undefined-JS-CSS.json` — ошибочные заполнители. Имя компонента — `FlipCard`. Официальный JS-CSS исходник доступен по https://reactbits.dev/r/FlipCard-JS-CSS.json, но для существующего TypeScript проекта выбран эквивалент TS-CSS. Tailwind не требуется.

Команды официального реестра для проектов с настроенным shadcn:

```sh
npx shadcn@latest add @react-bits/FlipCard-TS-CSS
npx shadcn@latest add @react-bits/FlipCard-JS-CSS
```

В этом проекте компоненты уже импортированы вручную из реестров. Повторно запускать установку не нужно.

Фото-воспоминания используют `front` для фотографии, `back` для личной записки, управляемые `flipped` и `onFlipChange`. Переворот запускается нажатием; Enter и пробел работают с клавиатуры. Наклон и блик деликатные, цвета и бумага соответствуют mybusik. Длинные записки получают меньший шрифт.

Внутри Carousel передаём `draggable={false}`: горизонтальный свайп листает фотографии. Локальная адаптация использует `click` для такого режима вместо `pointerup`, чтобы Carousel и MobileScroll успевали отменять активацию после перетаскивания. Самостоятельный режим draggable исходника сохранён, но пока не используется и не проверен в интерфейсе.

При выборе «Фото с подписью» показывается обычная статичная карточка. При системном reduced motion объёмный переворот заменяется немедленным переключением сторон; эффект блика скрыт.

## Magic UI: Confetti

- Репозиторий: https://github.com/magicuidesign/magicui
- Исходник: https://magicui.design/r/confetti.json
- Локальный файл: `src/components/magicui/confetti.tsx`.
- Импорт: `import { Confetti } from './components/magicui/confetti';`
- Зависимости: `canvas-confetti`, типы `@types/canvas-confetti`.

Сохранён компонент canvas; ненужная обёртка ConfettiButton и зависимость от shadcn Button исключены. Используются уже существующие кнопки mybusik. Canvas локален для механики, не перехватывает указатель и очищается при уходе с этапа. Эффект запускается самим компонентом при монтировании, чтобы повторная проверка эффектов React StrictMode не отменяла единственный запуск из родителя.

Конфетти срабатывает при раскрытии секрета, заполнении сердца, завершении пазла, результате автомата и получении купона. Промежуточные касания сердца сохраняют небольшие частицы-сердечки. Спокойные варианты секрета, сердца и пазла не запускают конфетти при входе. При reduced motion частицы не показываются.

## Источники и обновления

`animation-sources.json` хранит адреса реестров, дату получения и SHA-256 полученных JSON. Лицензии и перечень локальных адаптаций — в `THIRD_PARTY_NOTICES.md`. Обновления выполняем осознанно, сравнивая новые исходники с нашими изменениями; автоматической загрузки с GitHub во время работы сайта нет.
